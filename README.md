Student Record dApp
MG3012 - Blockchain Technology for Business

Assignment Description

This assignment is a simple Student Record dApp made using Solidity, HTML, CSS and JavaScript. It allows students to add, view and update their records using a blockchain network.

Features

- Connect MetaMask wallet
- Add student record
- View student record
- Check if a record exists
- Update student record

How to Run the Assignment

1. Install MetaMask and select the Sepolia test network.
2. Open the project folder.
3. Open CMD inside the project folder.
4. Run the command: python -m http.server 8000
5. Open http://localhost:8000 in your browser.
6. Click Connect MetaMask and approve the connection.
7. Enter student details and use the Add, View and Update buttons.

The smart contract was compiled and deployed using Remix IDE. The website connects to the contract through MetaMask.
